Simple Search Engine App Using Langchain + DuckDuckGo

This project is a minimalist search tool that integrates DuckDuckGo with Langchain to enable real-time, LLM-powered information retrieval.

It leverages the DuckDuckGoSearchRun tool from langchain_community.tools and supports multiple LLMs using Azure OpenAI APIs.

💡 Core Langchain concepts used:

  • Models — the LLMs (OpenAI, Gemini or Azure OpenAI) used to generate or process language-based output.
  • Prompts — instructions or input templates provided to the model to guide its responses.
  • Chains — sequences of calls (prompts + models) that execute in order to perform a task.
  • Indexes — data structures (like vector stores) that enable efficient document retrieval.
  • Memory — lets the application remember past interactions across conversations.
  • Agents — components that use tools and models to dynamically decide what actions to take.

The architecture is modular, and the backend is built using Flask. Users can test search queries by running a local server and using curl or frontend tools.

🧪 Example usage:

curl -X POST http://localhost:5000/news \
  -H "Content-Type: application/json" \
  -d '{"query": "Hiking tips to mountains"}'

The project uses environment variables to protect sensitive keys. Check out the included .env-sample and set up accordingly.
